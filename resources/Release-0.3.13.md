# Markit 0.3.13

## 本次更新

- 双栏升级为 Nature 风格 A4 分页版式：首个一级标题通栏，正文双栏，包含页间分隔和页码。窄窗口自动缩放整页。
- 双栏支持直接点击内容编辑 Markdown，按 Ctrl+Enter、Esc 或“完成编辑”返回排版。保存、撤销与重做和全文源码共用同一份文稿。
- 修复 Ctrl+V 粘贴长文本后页面跳转，保持当前阅读位置，粘贴可整批撤销；图片粘贴沿用相同位置保护。
- 修复从即时排版标题开头拖选复制时遗漏 Markdown `#` 的问题。
- 长表格按行续栏并重复表头，参考文献按条目分页，保留顺序；跨页内容进入和退出编辑时保持定位。
- HTML、PDF 和 PNG 同步分页样式。HTML 静态离线可用；PDF 默认 A4，仍支持 Letter；PNG 保留页间空隙。
- 增加“视图 → 显示行号”，源码逐行连续编号，单栏即时排版的渲染块显示起始源码行号。开启状态保存为全局偏好。
- 包含已合并的最后一个标签关闭修复、Linux 打包支持和 Markit 名称统一。Windows 升级继续使用旧版 Markedown 数据目录。
- 更新项目首页：下载入口、实际界面截图、功能分组、设置总览、开发文档与公开论文排版示例。
- 参考 nomo 增加表格节点编辑：单元格输入、Tab 移动、行列选择、右键增删、列对齐、调整尺寸及电子表格多单元格粘贴；保留科研三线表及源码编辑。
- 行内与行间公式增加 LaTeX 编辑面板和实时预览，保留分隔符、标签和自动编号，支持键盘完成、取消及边界退出；单栏与 A4 双栏均可使用。

## 使用与更新

双栏入口：**视图 → 论文版式 → 双栏（Nature 风格）**。点击表格和公式可打开节点编辑面板，表格样式仍可在偏好设置中调整。Pandoc 导出保持原有版式。

安装版：保存文稿并退出旧版，再运行新版 EXE 安装到原目录。便携版：解压到新目录，退出旧版后将原 `data` 文件夹复制到新目录，运行 `Markit.exe`。

提供 Windows x64 安装版与便携 ZIP，以及 Linux x64 AppImage、DEB、RPM 和 tar.gz；GitHub 自动提供 Source code。发行包未签名。

构建、测试与使用说明见 [README](../README.md)。
