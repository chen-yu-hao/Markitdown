# Markedown Windows 0.3.5

Windows 10 22H2 / Windows 11，x64。提供未签名安装程序与便携 ZIP。

## 本次更新

- 侧栏 Markdown 文件单击即可打开；已打开的文稿直接激活，保留未保存内容。支持 Enter 和空格，双击不会重复打开。
- 顶层正文段落仅包含一个 `$…$` 或 `\(…\)` 时，默认按行间公式排版。编号遵循已有设置，Markdown 源码不变。
- 在“偏好设置 → Markdown → 数学公式”新增“独占段落的行内公式按行间公式处理”开关。正文夹排、标题、列表、引用和表格中的行内公式不受影响。
- 修复 `$$` 和 `\[` 公式块紧接正文、前方没有空行时的识别。

## 安装与更新

安装版：保存文稿并退出旧版，运行新版 Setup.exe 安装到原目录。便携版：解压新版到新目录，复制旧版的 `data` 目录后启动；另行存放的文稿和图片保留在原位置。

使用与构建说明见 [README.md](../README.md)，验证范围见 [Validation.md](Validation.md)。
