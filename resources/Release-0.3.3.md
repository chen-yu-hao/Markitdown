# Markedown Windows 0.3.3

Windows 10 22H2 / Windows 11，x64。提供未签名安装程序与便携 ZIP。

## 公式排版

- 行间公式默认自动编号，默认公式左对齐、编号在右侧，相对多行公式整体垂直居中。
- 在“编辑 → 偏好设置 → Markdown → 数学公式”中新增公式左/中/右对齐与编号左/右侧设置，切换时保留源码和引用。
- “编辑 → 格式”提供独立的行间公式和行内公式入口；行间公式插入保留选区内容，可一次撤销与重做。
- 编辑器、HTML、无样式 HTML、PDF 和 PNG 使用所选布局。编辑器超宽公式可横向滚动，PDF/PNG 自动缩放超宽公式。
- Word 导出保留原生可编辑公式，并将编号放在独立位置；EPUB 和 LaTeX 导出同步传递公式布局。

旧版已经选择的“关闭自动编号”或“仅带标签”设置继续保留。需要为全部行间公式编号时，在数学公式设置中选择“所有行间公式”。

## 安装与更新

安装版：保存文稿并退出旧版，运行新版 Setup.exe 安装到原目录。便携版：解压新版到新目录，复制旧版的 `data` 目录后启动；另行存放的文稿和图片保留在原位置。

使用与构建说明见 [README.md](../README.md)，验证范围见 [Validation.md](Validation.md)。
