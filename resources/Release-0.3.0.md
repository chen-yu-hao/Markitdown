# Markedown Windows 0.3.0

发布日期：2026-09-07。Windows x64，未签名安装程序和便携 ZIP。

## 论文写作

- 新增“编辑 → 学术引用”，支持 Zotero 检索、多选插入、公式标签和公式引用。
- 直接输入 `[@D9PGQUM4; @T4IQZGRM; @MRHTZ5CI]` 可建立引用，支持数字制和作者年份制；数字编号按首次出现顺序更新。
- 通过 `http://localhost:23119/api/` 读取 Zotero 个人文库。已解析条目支持本地缓存，损坏缓存与缺失记录分别提示，不写入 Zotero 文库。
- 参考文献默认在文末，以独立行 `<!-- markedown:bibliography -->` 定位，移动该行即可调整位置。新引用与默认占位符可一起撤销；打开原有文件不会因此改写源码。
- 行间公式默认自动编号，支持仅带标签编号和按一级标题分节编号。行内公式也可以用 `\label{eq:...}` 添加稳定标签；使用 `\eqref{...}`、`\ref{...}` 或 `[@eq:...]` 引用并定位。
- 重复公式标签、缺失公式目标和未解析文献在编辑时提示，并在导出前检查。
- 支持普通 `\tag`/`\tag*` 手动编号优先和 `\notag`/`\nonumber` 取消编号，避免自动与手动编号重复。

## 导出与扩展

- HTML、PDF、PNG 与即时排版共用公式和引用规则；输出使用当前未保存内容。
- Pandoc 导出保留学术引用及书目位置。DOCX 使用原生可编辑数学对象，行间公式和编号同段，沿用 Word 字体、字号和颜色设置。
- DOCX 的公式编号、引用和参考文献是 Markdown 快照，不是 Word 自动编号域或 Word 引文管理器记录。
- LaTeX、RST、Textile、MediaWiki 导出的本地图片写入目标旁的 `markedown-assets-*` 目录，分发时须一并携带。
- 预留版本 1 的 Markdown 与文献提供器接口。内建公式、引文和 Zotero 使用同一接口约定；尚未提供外部插件加载或在线市场。
- 附学术写作说明、可编辑示例、扩展开发说明及完整依赖许可材料。citeproc-js 按 CPAL 选项分发，保留启动与设置署名。

具体测试范围和环境限制见 `Validation.md`。仍不包含自动更新、代码签名、Mermaid 或任意外部主题加载。
