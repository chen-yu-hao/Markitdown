# Markedown Windows 0.3.4

Windows 10 22H2 / Windows 11，x64。提供未签名安装程序与便携 ZIP。

## 标签与窗口

- 右键标签新增“打开新窗口”“关闭”“关闭其他标签”。操作针对右键选中的标签。
- 将标签拖离标签条后松开，可移到独立窗口；按 Esc 或拖回标签条取消。
- 移窗保留未保存内容、撤销与重做、选区、滚动位置、编辑模式及工作区。相同文件仍只打开一份。
- 新窗口成功恢复文稿后才移除原标签；加载失败、取消或超时会保留原窗口的文稿。
- “关闭其他标签”仅关闭当前窗口的其他文稿，沿用保存确认；取消或保存失败时保留标签。
- 菜单支持键盘操作，适配窄窗口和不同应用显示缩放。

## 安装与更新

安装版：保存文稿并退出旧版，运行新版 Setup.exe 安装到原目录。便携版：解压新版到新目录，复制旧版的 `data` 目录后启动；另行存放的文稿和图片保留在原位置。

使用与构建说明见 [README.md](../README.md)，验证范围见 [Validation.md](Validation.md)。
