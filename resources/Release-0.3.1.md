# Markedown Windows 0.3.1

发布日期：2026-09-07。Windows x64，未签名安装程序和便携 ZIP。

## 大图修复

- 修复粘贴、拖入或选择高分辨率图片时出现 `Input image exceeds pixel limit` 的问题。静态图片处理上限从 8000 万提高到 2.56 亿像素，超过上限时显示具体尺寸。
- 支持的原始图片导入后保留分辨率，大图预览默认使用 2048 像素以内的缓存缩略图。无旋转信息的 PNG 完整尺寸导出保留原始字节，避免不必要的重新编码。
- 图片转换串行执行，同一图片的并发预览请求共用处理结果；转换后重新检查单张 64 MiB、整批 256 MiB 的大小上限。
- 动画和多页图片仍限制为合计 8000 万像素、最多 500 帧；单批最多 100 张图片。

本版保留 0.3.0 的编辑、学术引用与导出功能。验证范围见 [Validation.md](Validation.md)，完整使用和构建说明见 [README.md](../README.md)。
