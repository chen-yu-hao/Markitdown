# Markedown Windows 0.3.2

发布日期：2026-09-07。Windows x64，未签名安装程序和便携 ZIP。

## 光标定位修复

- 修复含粗体、链接或公式的段落中，点击段末时光标偏到下方或下一空行的问题。标题、表格、代码和公式块的间距现在计入编辑器高度测量。
- 普通链接使用可编辑的文字装饰，点击段末不再跳到段首。自动链接和显式尖括号链接保持各自的 Markdown 解析规则。
- 展开当前段落源码时保留点中的字符，并补偿垂直位置。覆盖短文稿、窄窗口、上方段落收起，以及点击后立即输入的情况。
- 鼠标拖选、Shift 扩选、多击选择与打字机居中继续使用原有选择行为。

本版包含 0.3.1 的大图粘贴修复。验证范围见 [Validation.md](Validation.md)，完整使用和构建说明见 [README.md](../README.md)。
