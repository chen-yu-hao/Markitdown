# Windows 0.2.0 验证记录

日期：2026-09-06。Windows 11 x64、Node 24.14.0、Electron 44.2.0。

## 本次已验证

- TypeScript 与生产构建通过。
- Vitest：121 项通过、1 项符号链接权限跳过，共 11 个测试文件。
- 测试包含原版数据可靠性，以及新增设置迁移、并发最近记录、文件筛选、换行默认值、图片设置、导出主题/无样式 HTML、Pandoc 格式参数、文档导入资源、编辑配对/缩进/列表、智能标点、自定义快捷键、大纲语法一致性。
- 已增加实际 Electron 回归脚本 scripts/verify-ui-v2.mjs，并为旧完整 smoke 适配新菜单。

## 未通过最终验收的项目

- 新版实际 Electron 界面测试在沙箱内启动时，GPU 子进程退出（-1073741515），随后 Playwright CDP 连接断言失败；尚未执行任何界面检查断言。
- 沙箱外运行申请被自动审批服务以 HTTP 429 / exceeded retry limit 拒绝，命令未执行。Mermaid 依赖下载申请同样被拒绝。
- 因此不能将旧版截图或旧版独立脚本结果作为本次新版界面、主题视觉、PDF/PNG 视觉、安装、卸载、系统 DPI 或真实中文输入法验收证据。
- Mermaid 在当前离线构建不可用，设置明确禁用，源码保留。

建议在允许 GUI 测试的 Windows 环境执行 npm run test:ui、npm run test:e2e、node scripts/verify-editor.mjs、node scripts/verify-main.mjs、node scripts/verify-exports.mjs、node scripts/verify-packaged.mjs 与 scripts/verify-install.ps1 -Execute。安装测试需独立可回滚环境。

## 重跑命令

```powershell
npm run build
npm test
npm run test:e2e
node scripts/verify-main.mjs
node scripts/verify-editor.mjs
node scripts/verify-exports.mjs
node scripts/verify-packaged.mjs
./scripts/verify-install.ps1
./scripts/verify-install.ps1 -Execute
```

实际运行脚本使用独立测试数据；安装检查拒绝覆盖已有 Markedown 安装、关联或快捷方式。`verify-install.ps1` 不带 `-Execute` 时只做预检。机器需要允许 Electron GUI 进程启动，人工输入法验收仍需单独执行。
