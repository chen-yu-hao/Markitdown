# Windows 0.2.2 验证记录

环境：Windows 11 x64、Node.js 24.14.0、Electron 44.2.0。日期：2026-09-07。

## 已完成

- TypeScript 检查与生产构建。
- 152 项单元测试通过，1 项真实文件符号链接测试因 Windows 创建权限跳过。覆盖新增设置校验、语法缩进、数学解析和边界、公式宏隔离、SVG/MathML 属性过滤、导出与 Word 排版。
- 实际 Electron 界面检查：紧凑顶栏、五种主题、七类可搜索设置、设置持久化、自定义快捷键、切换保存以及 900/700 像素窗口，共 8 组检查通过。
- 实际 Electron 全流程回归：共 16 组检查通过，覆盖 Unicode 和 Chromium IME 组合事件、跨标签撤销、模式切换、查找替换、大纲与工作区搜索、批量图片和撤销、BOM/CRLF 保存、包含未保存内容及本地图片的 HTML/PDF 导出、不同窗口尺寸与大文稿规则。35 万字符文稿打开测量为 60 ms（当前机器、当前测试文稿）。
- 二级菜单 4 组检查通过，覆盖悬停、方向键、分层 Escape、格式命令执行和撤销、文件菜单入口以及 150% 缩放下的滚动定位。
- Markdown 新功能 5 组实际 Electron 检查通过，且在打包程序上复验通过：LaTeX 分隔符、physics、math 代码块和跨区块编号；设置页面和紧凑窗口；默认代码语言和独立四空格缩进；系统剪贴板 SVG/MathML；HTML/无样式 HTML/PDF/PNG 含未保存内容导出。界面及导出 PNG 截图已检查。
- Word 任务的 14 项单元测试已纳入全量测试。独立 Electron 检查验证了字体、颜色、字号、标题粗斜体、持久化与重置；默认和自定义 DOCX 经本机 Word 打开及 PDF 页面检查。
- 实际打包程序验证通过：ASAR 启动、独立数据目录、Sharp 图片导入、本地图片协议与缩略图、HTML/PDF/PNG 导出、导出窗口清理，以及 100%/125%/150%/200% 应用显示缩放下的桌面与紧凑窗口。共 8 组检查，无渲染错误。
