# Markedown Windows 0.2.1

日期：2026-09-06。

- 简化“通用”设置中的产品信息，仅显示 Markedown 版本与平台。
- 统一主题、更新和高级设置提示，移除开发过程及与其他产品对比的文案。
- 保留现有主题、编辑、文件管理和导出功能。

支持 Windows 10 22H2 / Windows 11 x64。安装版和便携版均无需另外安装 Node.js；部分文档格式的导入与导出需要 Pandoc。

升级可运行新版安装程序。使用便携版时，解压至新目录后，将原便携版的 `data` 目录迁入新目录即可保留设置。迁移前关闭 Markedown 并备份数据。

当前暂不支持 Mermaid 图表预览、外部主题安装及自动更新。版本的实际验证范围见 `Validation.md`。
