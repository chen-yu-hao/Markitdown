# Markedown 0.3.10

## 本次更新

- 修复含参考文献、表格的文稿在上下滚动时跳动、卡顿或失去响应的问题。
- 保持屏幕外表格、公式和参考文献的排版占位，避免滚动经过这些区域时文档高度反复变化。
- 减少滚动中的重复排版，同时保留标签切换、跨窗口移动和恢复记录中的滚动位置。
- 保留 Markdown 原文、引用编号和表格样式设置。

## 更新方式

退出旧版后运行新版安装程序。便携版请解压到新目录，并在退出旧版后将原便携目录中的 `data` 文件夹复制到新目录。

安装版和便携版均为 Windows x64 构建；GitHub 发布页由 GitHub 自动提供 Source code 压缩包。
