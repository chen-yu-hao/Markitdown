# Markedown Windows 0.2.2

- 精简编辑菜单，正文至分隔线收进“编辑 → 格式”；打开、保存、导出位于“文件”。
- 新增代码缩进宽度、默认代码语言、自动填写时机和 Shift+Tab 语法缩进。
- 新增 LaTeX 公式分隔符、math 代码块、physics、行内公式兼容模式和独立公式自动编号。
- 公式复制及无样式 HTML 可选择 SVG 或 MathML。SVG 自带字形路径，可离线使用。
- 新增首行缩进、换行标记，以及独立的编辑/内建导出空格换行设置。
- 新增 Word 导出字体、颜色、正文及六级标题字号、标题粗斜体设置，默认宋体、Times New Roman 和黑色文字。
- 公式解析隔离宏定义，过滤链接、CSS 和远程资源属性，限制异常尺寸与缓存容量。

设置即时应用并保留文稿源码和撤销记录。Word 导出需要 Pandoc；内建导出无需外部工具。此版为 Windows x64 未签名发行包，支持手动升级，无自动更新。
