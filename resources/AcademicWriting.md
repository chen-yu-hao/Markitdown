# Markedown 学术写作

文稿始终保存为 Markdown。公式标签、文献条目键和参考文献占位符都是可见源码；显示编号与排版结果由这些源码生成。切换样式不会把引文替换为固定文字，也不会在文稿中写入隐藏的文献数据库。

## 文献引用

1. 打开 Zotero，启用其本地 API。Markedown 连接 `http://127.0.0.1:23119/api/`，读取当前个人文献库 `users/0`。
2. 在“编辑 → 偏好设置 → Markdown → 文献引用”中使用“检查 Zotero 连接”。
3. 把光标放到引用位置，打开“编辑 → 学术引用 → 插入文献引用…”。检索标题、作者或年份，勾选条目后插入；选择顺序决定写入源码的顺序。
4. 在“引文样式”中选择“顺序编号”或“作者与年份”。在 Zotero 中修改书目信息后，使用“编辑 → 学术引用 → 刷新文献数据”。

默认快捷键是 `Ctrl+Shift+C`。也可以直接输入引用源码：

```markdown
单条文献 [@D9PGQUM4]。

同一处引用三条文献 [@D9PGQUM4; @T4IQZGRM; @MRHTZ5CI]。
```

条目键是 Zotero 的八位大写字母／数字键，区分于 DOI、数字型数据库行号、Better BibTeX citekey 和附件文件名。本版面向个人库 `users/0`，没有群组库选择或任意 citekey 映射。上述三个真实条目键来自本次使用的个人库；换到其他文献库后，需要插入该库中实际存在的条目。

内建两种 CSL 样式，由 citeproc-js 排版：

| 样式 | 文内显示 | 文后列表 |
| --- | --- | --- |
| 顺序编号 | 按首次出现的条目顺序编号，例如 `[1]`、`[1–3]` | 按引文编号排列，同一条目重复引用保持同号 |
| 作者与年份 | 作者／作者缩写和年份 | 按作者、年份、题名排列 |

这些是 Markedown 的通用学术样式，不代表已经覆盖各期刊的全部投稿格式。目前没有外部 CSL 文件导入、引文页码定位符或脚注引文编辑器。切换样式保留原来的 `[@条目键]` 源码。

### 参考文献位置

首次通过面板插入文献，或在编辑时完成有效引文，文稿缺少占位符时会在末尾新增：

```markdown
<!-- markedown:bibliography -->
```

它应单独占据文稿顶层的一行，放在代码块、列表、引用块之外。把整行移动到需要的位置，列表就在那里生成；也可以把光标放到目的位置，使用“编辑 → 学术引用 → 设置参考文献位置”。例如让参考文献位于附录前：

```markdown
## 结论

结论正文。

<!-- markedown:bibliography -->

# 附录

补充推导。
```

一篇文稿保留一个占位符。复制出多个占位符会显示重复提示；把占位符写在代码围栏里只是展示示例，不会生成第二份列表。引文写在代码、公式、普通链接或注释中也保持其原来的含义，不参与文献编号。

### 本地连接与离线缓存

连接只访问本机回环 HTTP API，不需要 Zotero 网页账户令牌，不请求云端文献库，不读取笔记、注释、PDF 正文或附件文件。搜索每次最多显示 50 个候选条目，结果过多时应缩小检索范围。当前文稿最多解析 500 个不同文献键。

成功解析的书目 CSL 元数据缓存于应用数据目录的 `references/zotero/<条目键>.json`。安装版使用应用数据目录，便携版使用自己的 `data` 目录。缓存与 `.md` 文件分离，不会把题名、作者、DOI 或整条 CSL 数据塞进文稿。

连接有效时，解析器会在约五分钟后重新核验；“刷新文献数据”会主动刷新。Zotero 离线时，已成功缓存的引用仍可排版，面板显示离线／缓存状态。离线搜索不是整个 Zotero 文献库的副本。发现条目已经删除或不再是书目条目时，会清理它的旧缓存；某个缓存文件损坏不会阻止其他文献恢复。

从其他电脑复制 Markdown 时，条目键可能并不存在于新的个人库，且缓存不会随 Markdown 自动传输。无法解析的文献会保留键并提示。导出遇到缺失文献时会停止，并列出需要核对的键，避免生成看似完整但缺少参考文献的文件。

## 公式标签与引用

在“偏好设置 → Markdown → 数学公式”启用需要的分隔符。支持 `$…$`、`\(…\)` 行内公式，以及 `$$…$$`、`\[…\]` 和 `math` 代码块形式的独立公式。

将标签写在公式源码内部：

```markdown
能量关系见 \eqref{eq:energy}。

$$
E = mc^2 \label{eq:energy}
$$

行内量 $\eta = E/E_0\label{eq:ratio}$ 也可通过 \eqref{eq:ratio} 引用。
```

也支持紧随公式的标签标记，以及 `math` 围栏信息中的标签：

````markdown
$x = 1$ {#eq:inline}

\[
y = x + 1
\] {#eq:next}

```math {#eq:fence}
z = x^2 + y^2
```
````

标签须以字母或数字开头，可包含字母、数字、冒号、点、下划线、斜线和连字符，最长 128 个字符。推荐使用 `eq:energy` 这样的语义标签。标签不随显示编号改变；在前文插入新公式后，引用目标仍由标签确定。

| 引用源码 | 显示含义 |
| --- | --- |
| `\eqref{eq:energy}` | 带括号的公式编号，例如 `(2)` |
| `\ref{eq:energy}` | 不带括号的公式编号，例如 `2` |
| `[@eq:energy]` | 与 `\eqref` 相同，采用带括号编号 |

可以先写引用、后定义公式。整篇索引会解析前向引用，并让局部预览、复制和导出使用同一编号。行内标签同样可引用，并参与编号序列。公式标签重复时，公式旁会显示诊断，相关引用显示 `[!! 标签]`；缺少目标时显示 `[?? 标签]`，不会任意选择一个公式。

把光标放入公式，使用“编辑 → 学术引用 → 为当前公式添加标签”；引用已有公式可使用同一菜单中的“插入公式引用…”，默认快捷键 `Ctrl+Shift+R`。在即时排版中按住 `Ctrl` 点击引用可定位目标。

### 编号设置

| 设置 | 行为 |
| --- | --- |
| 所有独立公式 | 独立公式自动编号；带标签的行内公式也获得可引用的编号 |
| 仅带标签的公式 | 未带标签的公式不自动编号 |
| 关闭自动编号 | 关闭无标签公式的自动编号；显式标签仍保留可引用编号 |
| 全文连续编号 | 全文使用 `1`、`2`、`3` |
| 按一级标题分章编号 | 每个 `#` 一级标题开始新章，显示 `1.1`、`1.2`、`2.1`；首个一级标题前为 `0.1` 起 |

文稿标题如果使用一级标题，也计入分章序列。编号是排版结果，不会被写回公式源码。重复标签与未解析公式引用的诊断也会保留在渲染结果中，应在交付稿件前修正。

普通的顶层 `\tag{A}` 或 `\tag*{S1}` 优先使用手动号码，不重复添加自动编号；配合标签后，引用沿用同一号码。`\notag`、`\nonumber` 取消该公式编号且不消耗自动序号。复杂 TeX 标签、多重标签或逐行手动编号不作为单一公式号码推断，保留源码并提示编号歧义，导出前需要处理。

## 复制与导出

“公式复制格式”可选择 SVG 或 MathML：前者保留外观，后者适合支持 MathML 的目标应用。实际可编辑程度取决于接收应用。Markdown 源码复制仍保留公式、标签与引文键。

文件菜单的 HTML、无样式 HTML、PDF 和 PNG 导出使用当前文稿快照，包括未保存的编辑内容，并带入已解析的文献与公式结果。Pandoc 格式需要另行安装 Pandoc；其格式限制与选项以导出设置为准。

DOCX 保留可编辑的原生数学对象，行间公式与编号同段。Word 中的公式编号和文献列表是导出时的 Markdown 快照，不是 Word 自动编号域或引文管理器记录。LaTeX、RST、Textile、MediaWiki 的本地图片保存在目标旁的 `markedown-assets-*` 目录，移动文稿时需携带该目录。

超过 1 MiB 的源码文稿暂停输入时的全文学术索引和自动占位符插入。主动插入文献或公式标签、刷新文献和导出仍按需计算，避免每次输入都同步解析长文。

示例文稿见同目录的 `AcademicExample.md`。扩展开发接口见 `Extensions.md`。
