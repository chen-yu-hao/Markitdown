# Markedown 0.3.11

## 本次更新

- 修复 Windows 上保存时页面跳动：更新最近文件记录不再触发表格、公式和参考文献的重复排版。
- 修复长图显示过窄：图片随正文宽度等比显示，取消页面和缩略图的高度限制，保留原始图片。
- 新增 Nature 风格双栏论文阅读，在“视图 → 论文版式”或“偏好设置 → 外观 → 字号与版式”切换；正文为双栏、主要标题通栏。
- 双栏版式同步到 HTML、PDF 和长图 PNG 导出，包含当前未保存内容。源码模式保留独立撤销和选区；按 Ctrl+/ 在双栏阅读与源码编辑之间切换。
- 修复 Ctrl+/ 被源码编辑器的注释快捷键拦截的问题。
- 包含仓库近期合并的关闭最后一个文稿、帮助与关于对话框修复。

## 使用说明

默认保留单栏即时排版。双栏为论文阅读与内建导出版式，内容修改通过“编辑源码”完成；版式选项为全局偏好。窄窗口中阅读区域自动收为单栏。DOCX 等 Pandoc 导出继续使用其原有版式。

## 更新方式

保存文稿并退出旧版后运行新版安装程序。便携版请解压到新目录，并在退出旧版后将原便携目录中的 data 文件夹复制到新目录。

提供 Windows x64 安装版和便携版，GitHub 自动提供 Source code（zip / tar.gz）。
