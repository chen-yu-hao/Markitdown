# Markedown Windows 0.2.0

日期：2026-09-06。此版本按用户提供的界面截图独立实现。

- 紧凑顶栏与原生 Windows 窗口按钮；移除 Logo 操作栏，偏好设置和格式操作归入编辑菜单。
- Github、Newsprint、Night、Pixyll、Whitey 五种内建主题，支持独立的系统深色主题；导出沿用当前主题。
- 七类可搜索偏好设置，支持编辑、Markdown、图片、文件、导出和 Windows 集成选项。
- 导出预设可增删、重命名和排序；新增无样式 HTML 与四种 Pandoc 文本格式。
- 配置切换保存时保留恢复文稿保护；主题与设置变更不重建编辑器撤销历史。
- 路径和数值输入在失去焦点或 Enter 时提交，支持含空格的 Windows 路径。

## 已知限制

Mermaid 下载与新版 Electron 界面验收受到自动审批服务 HTTP 429 阻断。当前构建的图表选项明确禁用，文稿与导出保留图表源码。尚无自动更新、第三方 CSS 加载、表格行列操作或文件操作撤销。

没有复刻 Typora 的许可证激活和匿名数据收集，也不宣称完成对 Typora 全部功能的替代或超越。Windows 10、真实输入法、DPI、安装与卸载仍需实际验收。
