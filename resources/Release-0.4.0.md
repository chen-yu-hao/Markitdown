# Markit 0.4.0

## 本次更新

- 新增审阅模式：直接使用文稿所在项目的 Git `HEAD` 作为基线，新增内容以红色下划线显示，删除内容以删除线显示，可逐条或一次接受变更。
- 已跟踪文件不再创建应用内部 Git 仓库；未跟踪文件需先保存并创建基线提交，不在 Git 工作区的文件只有在用户明确确认后才会执行 `git init`。接受修改会提交回用户项目，相关新粘贴图片也会随审阅提交处理。
- 标签和侧栏文件右键菜单增加“复制路径”和“在文件夹中显示”，便于在资源管理器中定位文稿。
- 表格节点采用 Nomo 风格的内嵌编辑面板，支持单元格输入、Tab/Enter 导航、行列选择、插入/删除、列对齐、批量粘贴、缩放和面板尺寸调整；表格样式继续同步到即时排版和导出。
- 语义编辑按最小 Markdown 节点显示源码，光标进入粗体、链接、公式等语法单元时只展开对应源码范围。
- 保留 A4 双栏、公式编号、Zotero 引用、行号、图片节点、Mermaid 图表和安全渲染能力。

## 兼容与升级

安装版覆盖安装即可升级，设置、恢复记录和缓存沿用已有 Markit/Markedown 数据目录。便携版请将新版解压到新目录，并复制旧版 `data` 目录。文稿格式和扩展接口保持兼容。

## 发布内容

本版提供 Windows x64 安装程序、Windows x64 便携 ZIP，以及 Linux x64 AppImage、DEB、RPM 和 tar.gz。GitHub Release 自动提供 Source code（zip / tar.gz）；安装包未签名。
